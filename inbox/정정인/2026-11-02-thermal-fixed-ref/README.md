## 요약

1. 같은 손난로 단계에서 `max`는 10/24 → 10/25에 1.1 °C 안에 머물렀고, `metric`은 최대 2.7 움직였다(11/2에는 앞 회차 남은 열로 55 °C `max`가 세 회차 45.96–48.21 °C, 2.25 °C 벌어짐 — §5). 흔들림은 중앙값(배경 온도)에서 온다 → [확인된 사실 1](#확인된-사실).
2. 하루 로그로 경계를 잡고 다른 날을 판정하면, 지금 방식은 50 °C 샘플 1,076개 중 259개(24 %)를 약불로 틀렸고, 고정 기준(`max − 23.0`)은 두 방향 모두 전부 맞혔다 → [확인된 사실 2](#확인된-사실).
3. 코드 변경은 선택 키 하나(`P_T_ref_c`)다. 키가 없으면 지금과 똑같다. 판정 시험 38개(새 1개) 통과 → [시험 기록](#시험-기록).
4. 값: `P_T_ref_c` 23.0, `P_T_mid` 17.46 · `P_T_high` 21.88 (여유 1.32 · 1.23), `P_T_danger` **26.50 = 최고 49.5 °C**(PM 11/2). 55 °C 손난로와의 여유는 11/2 최고 48.21 °C 기준 **1.29 °C**(10/24·10/25 최고 47.32 °C 기준이면 2.18 °C). 강불 쪽은 11/2 55 °C 최고 45.96 °C와 경계 44.88 °C 사이 1.08 °C.
5. 위험 판정 시각 재생(E2E 1–3회차 + 10/27 촬영 4회): 49.5 °C면 3회차 **+4.0 s**, 1·2회차 −95.5 · −13.0 s(더 일찍), 촬영 4회 0 s. 가운데 50.59 °C였다면 3회차 +23.5 s → [확인된 사실 4](#4-위험-판정-시각-재생-실측).
6. **11/2 추운 박스(중앙값 20.4–22.3 °C)에서 지금 방식이 두 번 과열을 냈다** — 55 °C 손난로(#215 ⓑ 3회차)와 인센스 불씨(병직 ⓓ 사전 확인). 같은 순간을 고정 기준으로 세면 둘 다 강불이다 → [확인된 사실 5](#5-11월-2일-추운-박스-사례-실측).
7. 차가운 빈 장면(최고가 기준보다 낮음)에서 metric은 0 아래로 안 간다 — 앱 파서·계약(minimum 0) 보호. 시험으로 확인.
8. **확인 필요**: E2E 1회차 20:26:19–20:27:35에 강불(high) 장면 최고가 49.98 °C까지 올랐다. 이 손난로가 55 °C였다면 49.5 °C 경계에서 과열 경고가 났을 장면이다 → [남은 문제](#남은-문제-추정과-확인-방법).

### 2. 날짜 교차 검증 [실측]

한 날 로그만으로 경계를 잡고(아래 단계 최대 + 위 단계 최소의 중간, 둘째 자리 내림) 다른 날 로그의 샘플이 맞는 단계로 가는지 셌다. 10/24에는 50 °C 회차가 하나, 10/25에는 둘이다.
